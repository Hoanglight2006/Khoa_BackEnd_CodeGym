BÀI THỰC HÀNH: 3 CÁCH NHÚNG CSS VÀO HTML

Phần 1: Inline-Style

Tiêu đề sử dụng Inline-Style

Đây là đoạn văn bản được định dạng trực tiếp bằng thuộc tính style="..." ngay bên trong thẻ <p>.

Phần 2: Internal-Style

Tiêu đề sử dụng Internal-Style

Đây là đoạn văn bản được định dạng bằng CSS nội bộ, khai báo thông qua cặp thẻ <style> đặt trong phần <head> của trang.

Phần 3: External-Style

Tiêu đề sử dụng External-Style

Đây là đoạn văn bản được định dạng bằng file CSS độc lập bên ngoài (style.css), được nhúng vào thông qua thẻ <link rel="stylesheet" href="style.css">.
